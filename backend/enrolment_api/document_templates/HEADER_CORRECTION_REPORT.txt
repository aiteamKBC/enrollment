PDF HEADER CORRECTION — 9 November 2026
Branch: compliance-documents. No commit, push, merge, rebase or branch switch.

Root cause
----------
brandedPage previously selected different image sizes and coordinates according
to page number. First-page KBC/DfE widths were 47/37 mm; continuation-page widths
were 30/24 mm. Body clearance also changed from 29 to 21 mm. Transparent padding
in the DfE PNG made its image rectangle an unsuitable visible alignment guide.

Shared geometry for new PDFs
---------------------------
documentHeader.ts now calculates one header for every page from the supplied
PNGs' nontransparent bounds. Natural image proportions are preserved.

                             KBC                         DfE
Old first image W x H (mm)    47 x 21.57                   37 x 35.15
Old later image W x H (mm)    30 x 13.77                   24 x 22.80
New image W x H (mm)          42.16 x 19.35                32.73 x 31.09
New visible W x H (mm)        40.62 x 18.00                30.44 x 18.00
New image x / y (mm)          9.13 / 15.23                 168.42 / 9.45
New visible x / y (mm)        10.00 / 16.00                169.56 / 16.00

The image rectangles include transparent padding. BOTH visible artworks start
16 mm below the paper edge, end at 34 mm, and retain 8 mm clearance to the normal
42 mm body start. Custom header text and larger configured margins can reserve
additional space. DfE's apparent y=9.45 is transparent padding, not visible art.

The requested 22–25 / 20–23 mm heights were suggested starting points. Actual
inspection favoured 18 mm visible height: smaller than the old first-page visible
heights (KBC 20.07 / DfE 20.35 mm), larger than continuation heights (12.81 / 13.20),
and balanced on A4. Original PNG resolution and aspect ratios are unchanged.

Limits / review notes
---------------------
Reserving the same comfortable header on all pages reduces usable page height.
Normal pagination may therefore change (sample Apprenticeship Agreement: 3 to 4
pages). Content was not shortened, fonts were not shrunk, explicit page breaks
were retained, and no empty page was found in the eight generated samples.
Header appearance changes apply to new presentation snapshots. Viewing an old
issued/signed document deliberately continues showing its stored old header.
No interactive production-account or external signing action was performed;
workflow regressions used isolated test fixtures and the actual PDF renderer.
